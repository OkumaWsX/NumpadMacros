# Publicador de Numpad Macros

Programa solo para el creador: arrastras la versión nueva (`NumpadMacros-codigo_X.Y.Z.zip`), revisa que todo
esté bien, la sube a GitHub y pone a trabajar al robot «Publicar versión».

- Ejecutar desde el código: `pip install -r requirements.txt` y `python publicador.py`
- Empaquetar en un solo archivo: `pyinstaller --noconfirm Publicador.spec`

Guía completa: [docs/PUBLICAR.md](../../docs/PUBLICAR.md)
